Реалізуйте у файлі `src/cli.js` консольну утиліту, яка виконує обчислення над числами, переданими як аргументи командного рядка.

```
node src/cli.js <операція> <число1> [число2 ...]
```

### Операції

| Операція | Результат | Приклад | Вивід |
|---|---|---|---|
| `sum` | сума | `node src/cli.js sum 1 2 3` | `6` |
| `avg` | середнє арифметичне | `node src/cli.js avg 2 4 9` | `5` |
| `min` | мінімум | `node src/cli.js min 3 -1 2` | `-1` |
| `max` | максимум | `node src/cli.js max 3 -1 2` | `3` |
| `median` | медіана (для парної кількості - середнє двох центральних) | `node src/cli.js median 4 1 3 2` | `2.5` |

### Вимоги до чисел і виводу

- Число - ціле або десяткове, можливо від’ємне: `7`, `-3`, `2.5`, `-0.75`. Роздільник - **крапка**.
- Не є числами: `abc`, `1,5`, `12px`, порожній рядок, `NaN`, `Infinity`.
- Результат виводиться в **stdout** одним рядком, округлений **не більше ніж до 2 знаків** після крапки без зайвих нулів: `1.5`, `1.33`, `0.3`, `42`.

### Довідка

`--help` або `-h` виводить у stdout довідку, що починається з `Usage:` і перелічує всі операції. Код виходу - `0`.

### Помилки та коди виходу

Повідомлення про помилку виводиться в **stderr** і починається з `Error:`; stdout при цьому порожній.

| Ситуація | Код виходу |
|---|---|
| успішне обчислення, довідка | `0` |
| немає аргументів, невідома операція (регістр має значення: `SUM` - помилка) | `1` |
| операцію вказано, але не передано жодного числа | `2` |
| хоча б один аргумент не є коректним числом | `3` |

# Етап 2: Консольна утиліта та обробка даних

## Предметна область 

Обрана предметна область — продукти харчування (молочні продукти, м'ясні вироби, солодощі)
Набір даних містить 20 записів у форматі JSON (`data/items.json`) із полями `id`, `title`, `category`, `price`, `quantity`, `date`

## Структура модулів

- `src/data.js` — модуль завантаження та перевірки даних з файлу `items.json` 
- `src/query.js` — чисті функції для обробки даних: фільтрація (`filterItems`), групування (`groupCount`), статистика (`stats`) та вибірка топ-N (`topN`)
- `src/query.js` — головна консольна утиліта для взаємодії через термінал з контролем кодів виходу (exit codes 0–4)

## Запуск

Запуск автоматичних тестів:
  `npm test`


### Опис команд та параметрів утиліти `report.js`

Утиліта підтримує такі основні команди:

`list` — виводить відфільтрований список товарів
   - `--category <назва>` — фільтрація за категорією (наприклад, `солодощі`, `молочні продукти`)
   - `--min-price <ціна>` — мінімальна ціна товару
   - `--max-price <ціна>` — максимальна ціна товару

`group` — групує дані та рахує кількість елементів у групах
   - `--by <поле>` — поле для групування (підтримуються значення `category` або `year`)

`stats` — виводить загальну статистику по складу (кількість позицій, загальна вартість, середня, мінімальна та максимальна ціна)
   - Може додатково фільтруватись за допомогою `--category <назва>`

`top` — виводить топ-N елементів за вказаним критерієм
   - `--n <кількість>` — кількість позицій у вибірці (ціле число від 1)
   - `--by <поле>` — критерій сортування (підтримуються `price` або `quantity`)

Загальні параметри:
- `--file <шлях>` — дозволяє вказати альтернативний шлях до JSON-файлу з даними (за замовчуванням використовується `data/items.json`)


### Приклади використання консольної утиліти:

1) Фільтрація товарів за категорією та ціною:
`node src/report.js list --category солодощі --max-price 100`

2) Групування товарів за категоріями:
`node src/report.js group --by category`

3) Перегляд загальної статистики:
`node src/report.js stats`

4) Вибірка топ-товарів за ціною:
`node src/report.js top --n 3 --by price`
